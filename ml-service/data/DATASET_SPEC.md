# AccessFlow Priority Dataset — specification

## Data origins (never mixed in one file)
| `data_origin` | Meaning | May be used for reported results? |
|---|---|---|
| `own_collected` | Findings collected by `server/scripts/collect-dataset.js` from public pages, then human-labelled | **Yes** (if quality gates pass) |
| `synthetic_fixture` | Generated by `tools/make_synthetic_fixture.py` to test code. Labels follow an arbitrary toy rule | **No. Never report its metrics as model performance** |

No verified public dataset with human High/Medium/Low priority labels exists for this task (see `DATA_PROVENANCE.md`).

## Unit
One row = one axe rule failing on one page (nodes aggregated; up to 50 nodes stored, `node_count` is the true count).

## Files
1. **Raw** `data/raw/<run>.jsonl` — collector output, no labels.
2. **Annotations** `data/annotations.csv` — filled sheet (template: `data/templates/annotation_template.csv`).
3. **Dataset** `data/dataset_<version>.jsonl` — raw fields + `final_label`, `label_method`, `split`. Built by `tools/build_dataset.py`.
4. **Split manifest** `data/splits/split_manifest.json` — domain → train/test. Existing domains never move (locked test set).
5. **Quality report** `data/reports/quality_<version>.json`.

## Raw / dataset fields
`finding_id`, `data_origin`, `collection_run_id`, `collected_at`, `page_url`, `registrable_domain`, `axe_version`, `ruleset_id`,
`rule_id`, `axe_impact` (scanner output, kept separate from the label), `axe_description`, `help_url`, `tags[]`,
`wcag_criteria[{criterion,level}]`, `node_count`, `page_finding_count`, `dedupe_key`,
`nodes[{selector, html_snippet(≤500 chars, values redacted), tag, role, is_interactive, landmark, failure_summary}]`.
Dataset adds: `final_label` ∈ {Low, Medium, High}, `label_method`, `split`.

## Features (documented in code: `src/accessflow_ml/features.py`, exported to `feature_schema.json`)
`axe_impact, rule_id, rule_category, wcag_level, wcag_principle, element_group, landmark` (categorical);
`is_best_practice, node_count_log1p, interactive_ratio, page_finding_count_log1p` (numeric).
**Never features:** raw HTML, selectors, URL, domain, label, annotator fields, split, finding_id (enforced by a test).

## Quality checks (`tools/build_dataset.py` → report)
- Exact duplicates (same `finding_id`, or same domain + rule + dedupe key) must be 0.
- Required fields present; flagged/unlabelled/invalid rows excluded and **counted**, never guessed from axe impact.
- Label distribution per split; no oversampling before the split.
- Domain grouping: whole domains go to train or test (hash of seed + domain). One domain ≤ 5% of rows.
- Residual leakage risk: different domains sharing a CMS/theme. Document it as a limitation.

## Readiness gates (working rules of thumb, not validated standards)
All must pass before results are called "meaningful"; otherwise report as **exploratory** with failed gates listed:
real data only · ≥ 30 test examples per class · ≥ 40 domains · no domain > 5% · self-consistency weighted κ ≥ 0.6 · no duplicates · no missing required fields.

## Baselines and metrics (training phase)
Majority class, axe-impact→priority mapping, logistic regression, decision tree, random forest (tuned only with grouped CV on train).
Report per-class precision/recall/F1, macro-F1, confusion matrix; **High recall** is the headline metric. Test set is used once.
